# CinemaHOT v0.2.0

2026-10-17，本机试运行版本。

## 内容

- 页面名称调整为电影动态，新增AI影视创作分类和筛选提示词；首发表示直接来源，不保证全网最早报道。
- 54个登记信源：35个自动适配、19个external待接入；创作者账号范围见信源文档。
- 默认采集周期360分钟；本机后台守护脚本和四次巡检操作说明已归档。
- 日常额度支持独立起算点，批量处理历史回执仍保留。
- 增加服务器部署手册及信源管理说明。

## 更新步骤

1. 备份数据库及本机私有配置。源码包不含新闻数据、密钥、运行日志或依赖。
2. 安装依赖，执行项目数据库迁移（含0084_budget_daily_reset_at.sql），再构建网页。
3. 旧数据库信源间隔需在后台改为360分钟；seed只添加新ID，不覆盖已有配置。
4. 保留当前预算，迁移不会自动重置额度；新部署需独立配置采集和模型开关。
5. 本机固定时段巡检不随源码迁移，服务器按部署手册配置常驻worker并验证周期。

## 验证与限制

配置版本已通过类型检查、763项后端测试、网页构建及30项站点检查。浏览器测试32项通过，17项因测试浏览器缺失未运行成功。恢复抓取时35个来源中34个成功，ASC返回HTTP403。精选门槛尚未人工校准，不能把采集成功等同事实准确。
