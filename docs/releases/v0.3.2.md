# CineHOT v0.3.2

2026-10-27。运维改进，读者页面没有变化，没有数据库迁移。

## 内容

- **飞书告警可以打开**：`deploy/vps/compose.yml` 的 worker 不再写死 `FEISHU_INTERNAL_ENABLED=false`，改为读 `.env`。配上飞书自建应用的 App ID、App Secret 和群 ID 后，积压、缺期、信源连续失败、付费服务拒绝等告警和读者反馈会发到运维群。
- **费用估算**：`check.sh` 第 4 段按 token 用量乘 `service_prices` 单价估算近 24 小时费用（原来汇总的 `cost` 字段对模型调用一直为空）。升级文档录入 deepseek-flash 高峰价：每百万 token 输入 2 元、缓存命中 0.04 元、输出 8 元。
- **校园服务器交接**：`docs/deployment/campus.md` 写明交给下一个 Agent 的事项（停程序改镜像、重启后重新登录校园网）。

## 更新步骤

按 [升级到 v0.3.2](../deployment/upgrade-v0.3.2.md) 执行。

## 验证与限制

`check.sh` 的费用查询在测试库上用已知用量验证（100 万输入、一半命中缓存、25 万输出 → 3.02 元）；飞书测试告警命令在本机关闭开关时输出 `disabled`。改过的 `compose.yml` 本机没有 Docker，未用 `docker compose config` 校验，由部署时的 `dc config` 验证。估算按高峰价，实际扣费以 DeepSeek 账单为准。
