# CineHOT v0.3.0

2026-10-24。同步上游、品牌调整、信源清理，部署改为“GitHub 构建镜像、VPS 拉取、校园镜像”。

## 内容

- **同步上游 AIHOT 60 个提交**（8ef28eb..b3998dc）：正文版本与发布可靠性、搜索拆词与相关度排序、内嵌 SVG 图保留文字说明、没有内容的周报月报不再出刊并停止重复报错、模型额度用尽时的冷却、登录与反馈修复、依赖安全更新；5 个新迁移（0085–0089），均可在线执行。合并时保留本站的分类、提示词、信源、每日预算重置与正文改写地址等定制。
- **品牌**：项目品牌统一为 CineHOT；英文站名改为 Global Cine News；导航去掉摄影系 Logo 图片，只显示站名。服务器目录、数据库名、镜像名与 MCP 工具前缀不变。
- **信源 94 → 87**：按两轮人工标注（274 条）移出蜂鸟网、色影无忌、NYU Tisch、NFTS、Unreal Engine Film & Television；移出一直拒绝采集的 ASC 订阅与 CineMontage；修复 Anthropic 新闻列表。评审记录与观察名单见 [信源评审记录](../sources/reviews.md)。
- **清除移出信源的数据**：新增 `scripts/purge-sources.ts`，已发布文章先走撤下流程，再删除文章、仅由它们支撑的事实与信源记录。
- **模型调用上限**改为每分钟 20、每小时 500、滚动 24 小时 2000。
- **部署协同**：推送版本标签后 GitHub Actions 构建镜像并推到 GHCR；服务器用 `deploy/vps/upgrade.sh` 升级、`deploy/vps/check.sh` 只读核对；校园服务器改为只转发并缓存 VPS 主站（`deploy/campus/nginx.conf.example`）。
- 标注工具导出时保留往轮结果（`collect` 每轮会换掉样本清单）。
