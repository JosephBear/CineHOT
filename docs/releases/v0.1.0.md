# CinemaHOT v0.1.0

发布日期：2026 年 10 月 15 日。用途：本地试运行，尚未公开上线或完成校园部署。

## 本版内容

- 网页导航使用摄影系提供的完整 JPG，保留 CinemaHOT 站名；电脑端与 320/390px 手机端均验证。
- 17 个信源默认固定 480 分钟采集，每日自动调整不会改回 60 分钟；失败重试不早于配置间隔。第三方请求预算耗尽仍按原机制等待配额恢复。
- Blackmagic 正文通过官方同源公开片段读取，原文链接和相对链接基准保留公开文章 URL，并继续执行 SSRF 与重定向检查。
- 新增部署、信源管理、运行维护、质量校准、品牌和版本记录文件夹，以及校园 Nginx 配置模板。
- 版本号写入 `VERSION`、根 `package.json` 和锁文件；站内更新日志同步记录。

## 本机运行配置

按使用者授权开启自动采集和 DeepSeek 默认模型测试：`llm` 服务 20 次/分钟、60 次/小时、120 次/滚动 24 小时。请求次数不是人民币硬上限。密钥、请求预算、模型调用记录、新闻数据和本机观察任务不进入仓库；新部署的采集与模型仍默认关闭。

本机已经验证真实 Blackmagic 正文读取，首轮采集 17 个信源中 16 个完成、ASC 返回 HTTP 403。部分海外请求仍可能间歇失败，不表示全部来源已稳定可用。

## 已有部署升级

没有新增数据库迁移。按[部署更新流程](../deploy.md#更新)备份、构建并更新服务。

1. 在后台将已有普通信源的采集间隔改为 480 分钟。每日调整会保留站点固定间隔，但更新文件不会立即覆盖数据库中旧值。
2. 在 Blackmagic 现有完整配置中补入[正文规则](../sources/README.md#blackmagic-正文规则)。`scripts/seed.ts` 只添加新 ID，不会覆盖该配置。
3. 需要开启付费测试时，先核对预算及模型单价，再显式打开 `.env` 开关并重启相关进程。
4. 文档已归入分类文件夹，旧 `docs/cinemahot-*.md` 路径已迁移，入口见[文档导航](../README.md)。

发布前运行类型检查、完整后端及独立测试、网页构建、网页回归和实际站点冒烟检查。正文与间隔变更包含先失败、后通过的回归测试。
