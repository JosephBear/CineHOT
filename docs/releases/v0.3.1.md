# CineHOT v0.3.1

2026-10-27。只改品牌显示。

## 内容

- 导航左上角换成摄影机图标（两个片盘、机身、遮光斗，机身上的录制灯用 `--hot` 色）加大字 Cinehot；电脑侧栏下面一行是“全球影像动态”，去掉英文名 Global Cine News；手机顶栏只显示图标和 Cinehot。
- `SITE.nameEn` 改为 Cinehot，首页标题改为“Cinehot 全球影像动态 — …”。

## 更新步骤

推送 `v0.3.1` 标签后 GitHub 自动构建镜像。服务器在 `/opt/cinemahot` 取出新版 `upgrade.sh` 后运行 `sudo bash upgrade.sh v0.3.1`，再运行 `check.sh` 核对。本版没有迁移，也没有需要单独执行的步骤。

## 验证与限制

类型检查、后端 970 项与不需要浏览器的 37 项网页测试通过；在本机浏览器核对了电脑侧栏（1280 宽）与手机顶栏（375 宽）的显示。网站图标（favicon）仍是胶片卷，未改。
