# CineHOT v0.3.5

2026-11-24。内容范围收窄到电影、电影制作、电影教育与AI影视创作，新增影像教育单元；读者文案与用词修正。没有数据库迁移，没有新的环境变量。

## 内容

### 影像教育单元与领域收窄（PR #5）

- **新类别“教育”**（key `edu`，上线后不能改）：筛选栏新增“教育”，网址 `/all?category=edu`，分类订阅 `/feed/category/edu.xml`，日报单独一节“影像教育”。新分类标签“课程/教学”，主题标签编剧、导演、剪辑、大师班、影视院校；新主题页“影像教育”（`/topics/film-education`）和编剧、导演、剪辑三个方向页。
- **收什么**：成体系的课程与公开课、创作者讲授方法的大师班与讲座、影视院校的教学方法与学生作品复盘、AI进入电影课堂等教育本身的变化。单条可照做的技巧仍归“教程”；院校的招生宣传、教职任命、校庆不收。评分中讲清方法的教学内容按教程正常评价，原“课程、讲座一律压低”改为只压纯招生广告。
- **6 个教学来源**（都不是院校新闻页）：YouTube 的 Film Riot、Film Courage、BFI、Gnomon、Curious Refuge，以及编剧教学博客 Go Into The Story。
- **领域收窄**：依据 10-21 至 11-18 共 566 条日报条目的评审，约 20% 是噪声。预筛不再放行与影视无关的静态摄影、游戏美术和消费电子，评分把这三类压低。移出 World Press Photo；Fstoppers、PetaPixel、80.lv 加标题过滤。头部AI模型发布照常放行。信源由 87 个变为 92 个。评审数据见[信源评审记录](../sources/reviews.md)。

### 读者文案与用词（PR #3）

- **关于页与站点简介**：删掉“当前仅本地试运行，精选门槛尚未人工标注校准”等过时说法。站点简介、首页标题和关于页统一写明更新节奏：每天更新精选，每天 08:00 出日报，每周一 10:00 出周报。简介同时用于 meta、og、JSON-LD、RSS 和 llms.txt。
- **读者用词规则**：`industry/wording.ts` 新增两条（rookie；Black Nights / 黑 nights → 塔林黑夜电影节）。写作完成后命中的词由模型只改一次；不命中不增加调用。
- **影展译名**：`industry/prompts/rules-domain.md` 补 14 个常见影展的中文名，并规定影展名不能只译一半。
- **版本记录**：补上 v0.3.3、v0.3.4 的记录与站内更新日志。

## 更新步骤

1. 按 [Oracle 部署模板](../../deploy/oracle/README.md) 的“已有 Oracle 项目升级”执行，镜像用 `ghcr.io/josephbear/cinehot-app:v0.3.5` 的清单摘要。升级时会运行 `scripts/seed.ts`，6 个新信源自动加入。
2. 在后台“信源”页把 Fstoppers、PetaPixel、80.lv 的配置改成与 `industry/sources.json` 一致（新增 `ingestNoiseFilter`）。种子脚本不覆盖已有信源的配置。
3. 清理 World Press Photo 的历史文章：`node --env-file=.env scripts/purge-sources.ts --ids web-wpp-news`，先预览，确认后加 `--apply`。
4. 核对 worker 正在运行、`.env` 里 `COLLECT_ENABLED` 和 `MODEL_CALLS_ENABLED` 为 `true`，并确认有新文章入库。

## 验证与限制

PR #3、#5 的 CI 都通过：类型检查、网页构建、后端与网页测试、站点冒烟检查，以及 AMD64 / ARM64 镜像构建与 Oracle 升级恢复演练。6 个教学来源和 3 个加过滤的来源都用 `scripts/check-cinehot-sources.ts` 实测通过。

- 提示词改动只影响以后新写的内容，不重跑旧内容，也不改已有条目的分类；“教育”栏从升级后新收的内容开始积累。
- 精选门槛未改。新预筛会多拦一些条目，精选数量可能略降；上线一个月后应抽样标注复核教育类质量和静态摄影是否拦干净。
- 中文教学来源暂缺：影视飓风、B 站教学 UP 主没有可直接订阅的入口，需要自建 RSSHub 或公众号采集。
