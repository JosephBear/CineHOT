# CineHOT v0.3.5

2026-11-24。读者文案与用词修正；没有数据库迁移，没有新的环境变量。

## 内容

- **关于页与站点简介**：删掉“当前仅本地试运行，精选门槛尚未人工标注校准”等过时说法。站点简介、首页标题和关于页统一写明更新节奏：每天更新精选，每天 08:00 出日报，每周一 10:00 出周报。简介同时用于 meta、og、JSON-LD、RSS 和 llms.txt。
- **读者用词规则**：`industry/wording.ts` 新增两条（rookie；Black Nights / 黑 nights → 塔林黑夜电影节）。写作完成后命中的词由模型只改一次；不命中不增加调用。
- **影展译名**：`industry/prompts/rules-domain.md` 补 14 个常见影展的中文名，并规定影展名不能只译一半。只影响以后新写的内容，不重跑旧内容。
- **版本记录**：补上 v0.3.3、v0.3.4 的记录与站内更新日志。

## 更新步骤

按 [Oracle 部署模板](../../deploy/oracle/README.md) 的“已有 Oracle 项目升级”执行，镜像用 `ghcr.io/josephbear/cinehot-app:v0.3.5` 的清单摘要。升级后核对 worker 正在运行、`.env` 里 `COLLECT_ENABLED` 和 `MODEL_CALLS_ENABLED` 为 `true`，并确认有新文章入库。
