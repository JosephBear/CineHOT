# CineHOT v0.2.2

2026-10-19。站名“全球影像动态（Global Image）”。网站从按时段试运行改为长期持续运行。

## 内容

- 服务器定制收进仓库：朋友试用版使用规则与隐私说明（采集说明改为持续运行）；服务器模板 [`deploy/vps/`](../../deploy/vps/README.md)（小内存镜像、compose、Caddy）；试运行期间新增的“每小时采集”更新日志（去掉额度与余额信息）。
- 新增设置 `WORKER_MAX_CONCURRENCY`：限制每个任务队列同时处理的数量，取代服务器上挂载的 5 个源码副本（避免升级后旧副本盖住新代码）。不设置时行为不变。
- 试运行组件停用：DeepSeek 守护代理、只处理试运行后文章的过滤、翻译限量、暂停自动恢复。费用由数据库 `llm` 预算与付费回执控制；未处理的旧文章逐步补处理。
- 信源质量查询 `scripts/source-discovery/source-quality.sql`：增加“已处理数”“最近判定”，入选数按每篇资料最新判定计算，不再把未处理资料算作不相关。
- 升级文档按服务器实际方式重写：[升级到 v0.2.2](../deployment/upgrade-v0.2.2.md)；v0.2.1 升级文档标为已取代。

## 更新步骤

服务器严格按 [升级到 v0.2.2](../deployment/upgrade-v0.2.2.md) 执行。本版没有数据库迁移和新信源；回退只需恢复备份的 `compose.yml` 与 `.env`。

## 验证与限制

类型检查与全部测试通过（含新增并发上限测试）。`deploy/vps/compose.yml` 已用 YAML 解析器核对结构，本机没有 Docker，未运行 `docker compose config`，由升级第 6 步在服务器上检查。
