# CineHOT v0.2.1

2026-10-19，服务器试运行版本。站名为“全球影像动态（Global Image）”。

## 内容

- 站名改为全球影像动态，英文名 Global Image；导航中的“电影”改为“影像”；侧栏和“我的”页底部显示 AIHOT 开源署名。
- 信源调整为94个，全部自动采集：新增院校、影展、泛影像媒体、YouTube官方频道、大疆官方新闻；新增5本电影学术期刊（经 Crossref）、Film Comment、ASC 官方动态（经 Google News），以及富士、卓曜、蔡司、适马、徕兹、东正、Atlas、RED 的官方渠道；移出找不到采集入口的external来源和 AFI 新闻订阅。详见[信源目录](../sources/catalog.md)。
- 默认采集间隔改为60分钟；模型日常上限标准改为20/分钟、150/小时、1000/滚动24小时（每篇相关资料至少5次调用，200次会持续积压）。
- 精选首轮校准：用186条人工标注调整预筛与评分标准，门槛三级统一为32、`understandFloor` 为25。过程见[标注与校准](../quality/calibration.md)。
- 按线上观察补充三条规则：重要奖项与主要影展主竞赛的提名、入围名单进入精选，影展具体活动不进；与影像创作无关的音乐、演出、喜剧、综艺和明星活动在预筛拦截；产品发布给出名称、规格、价格或上市时间等事实的正常评价，只有夸赞的宣传稿压分。
- 修正评测脚本把未写作条目判为“不确定”的问题，并补测试；新增本地标注工具 `scripts/label-selection.ts`（只接受本机地址与 JSON 请求，防止其他网页改写标注）和信源侦测 `scripts/source-discovery/`（含近14天信源质量查询 `source-quality.sql`）。

## 更新步骤

服务器（Docker Compose）请严格按 [升级到 v0.2.1](../deployment/upgrade-v0.2.1.md) 逐步执行；下面是要点。

1. 备份数据库，拉取代码，执行数据库迁移（本版没有新迁移），重新构建网页并重启 api、worker、web。
2. 运行 `node --env-file=.env scripts/seed.ts` 添加新信源ID；种子不会覆盖已有配置，也不会删除已移出的来源，需在后台暂停旧external来源，并把已有信源的采集间隔改为60分钟。
3. 在后台“设置”把 `llm` 预算改为 20/分钟、150/小时、1000/滚动24小时。
4. 运行 `scripts/source-discovery/source-quality.sql` 查看近14天各信源表现，再决定删除哪些低效信源。
5. 提示词变化只影响之后处理的资料，已发布的条目不会重新评分。

## 验证与限制

类型检查、208项独立测试与765项数据库测试通过。三条补充规则未单独评测：首轮标注中几乎没有对应样本，需要用线上实际条目验证。
