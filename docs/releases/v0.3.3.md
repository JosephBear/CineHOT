# CineHOT v0.3.3

2026-11-20。同步上游、精选重新校准、Oracle 日报恢复与 ARM64 镜像。**有数据库迁移**（随上游新增 28 个，启动时自动执行），升级前先备份数据库。

## 内容

- **同步上游 AIHOT**：合并 174 个上游提交（自 `b3998dc` 起）。CineHOT 自己的改动保留：固定采集间隔、正文地址改写、侧栏标志与上游署名、`poweredBy` 关闭。
- **精选重新校准**：`scripts/label-selection.ts` 新增 `collect-db` 和 `offline`，用线上已经打过的分离线校准，不调用模型。用线上 400 条按十月标准复核后，精选门槛由 32 降为 **24**，`understandFloor` 由 25 降为 **20**；估计每天入选约 23 → 27 条，查准约 0.92 → 0.91，查全约 0.62 → 0.70。依据见 [标注与校准](../quality/calibration.md)。
- **标签页图标**：白底黑色摄影机轮廓（favicon、PWA 图标、apple-touch-icon）。
- **日报补跑**：新环境变量 `REPORT_HISTORICAL_DAILY_GAPS`（默认空）。只有过去的日期、并且是“窗口内没有已评审稿件”时才略过；手动补发和当期缺稿仍会报错。
- **ARM64 镜像**：推送版本标签后，在 AMD64 和 ARM64 原生 runner 分别构建，发布同一个多架构标签。新增 Oracle 的 Compose 覆盖文件和 Nginx 示例（`deploy/oracle/`）。
- **院校教育单元第 0 步**：名单与信源可达性调研，只有文档，见 [院校调研](../education/roster-research.md)。

## 上线前须知（来自上游）

- 飞书管理员登录已移除，后台改用 `.env` 里的管理员密码登录。
- 备份目录结构有变化，旧的备份脚本或定时任务要核对。
- 新增若干可选环境变量，不设也能运行，见 `.env.example`。

类型检查、生产网页构建、后端测试（1198 通过，2 跳过）、网页测试（67 通过）和站点冒烟检查通过。新门槛上线一周后，核对每天实际入选数量是否在 27 条左右。
