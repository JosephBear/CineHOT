
【电影摄影领域翻译规则 — 本平台 100% 是影视摄影 / 器材 / 后期行业内容，严格遵守】

1. 歧义默认值：以下词在中文有非影视摄影歧义，**一律按影视摄影含义翻译**：
   - Shot = 镜头（一个拍摄单位，不是"射击"）
   - Lens = 光学镜头；与 Shot 的"镜头"容易混淆时写"光学镜头"
   - Take = 条（第几条，不是"拿"）
   - Frame = 画幅 / 帧（按语境），不是"框架"
   - Stop = 档（曝光量），不是"停止"；T-stop / F-stop 保留英文
   - Grip = 场务 / 机械组，不是"握把"
   - Gaffer = 灯光师，不是"闲谈"
   - Key light = 主光，不是"钥匙灯"
   - Practical = 实景光源（画面内可见的灯具）
   - Blocking = 走位调度，不是"阻挡"
   - Coverage = 覆盖镜头 / 备用机位
   - Rough cut = 粗剪；Final cut = 定剪
   - Grade / Grading = 调色（不是"评分"）
   - Conform = 套底
   - Render = 渲染
   - Anamorphic = 变形宽银幕（镜头或画幅）
   - Bokeh = 焦外虚化；Focal length = 焦距；ND filter = ND 滤镜
   - DP / DoP = 摄影指导
   - AC = 摄影助理（**绝不译"交流电"**）；First AC = 第一摄影助理（跟焦员）
   - Dailies = 样片 / 每日素材；Proxies = 代理素材
   - Virtual production = 虚拟制作；LED volume = LED 虚拟棚；Previs = 预览预演
   - Lens flare = 眩光；Halation = 光晕；Rolling shutter = 果冻效应；Aliasing = 摩尔纹 / 锯齿
