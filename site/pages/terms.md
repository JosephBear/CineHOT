# 使用规则（本地试运行）

版本：2026-10-15。本说明用于 CinemaHOT 的个人本地试运行，尚未作为公开服务上线。正式公开前须由使用者确认规则、运营主体和公开联系方式。

## 内容与来源

CinemaHOT 整理电影摄影相关公开信息。默认展示摘要与原文链接，不提供第三方全文再分发授权。原文及图片的权利归各来源所有；阅读、引用和进一步使用应查阅原站的要求。

当前模型和自动采集开关关闭。以后启用的模型摘要、分类与评分可能出错，器材参数、发布日期和政策内容应回到原文核实。精选门槛沿用初始值，尚未经过电影摄影人工标注样本校准；待标注清单不能证明筛选质量。

## 本地使用

网页、RSS、API 与 MCP 仅供这台电脑上的功能验证与个人阅读。暂不对外承诺服务稳定性、内容覆盖或更新时效。未经另行确认，不应将此试运行实例作为公开信息服务发布。

## 更正与反馈

本地操作者可通过反馈页记录问题，并在管理后台查看、处理或删除。当前没有公开联系邮箱，也没有启用向外部群转发反馈。若来源方提出更正或下架要求，由操作者核对原文并调整相应内容。

## 接口

RSS、API 和 MCP 是只读出口，请遵守缓存时间和限流响应。浏览页面不会自动触发付费模型调用。任何对外采集、模型或推送功能均需另行配置并显式启用。
