# 使用规则

版本：2026-11-26。CineHOT（全球影像动态）由 Joseph 维护，提供公开只读访问，不承诺服务持续可用、内容全面覆盖或更新时效。

## 内容与来源

本站聚合电影、电影制作、电影教育与 AI 影视创作领域的公开信息，默认展示摘要与原文链接。原文及图片的权利归各来源所有；进一步使用请查阅原站要求。模型生成的摘要、分类与评分可能出错，重要参数、日期与政策应回到原文核实。精选门槛已按人工标注样本完成两轮校准，仍可能出现漏选或误选。

## 访问与反馈

公开页面面向访客开放，请勿将站内反馈表单用于提交私密信息。可通过反馈页提交问题、更正或下架请求，由管理者查看处理。请勿提交密码、API key 或其他敏感材料。

## 接口与费用

RSS、公开 API 和 MCP 为匿名只读出口，请遵守缓存时间与限流响应。浏览页面不会触发付费模型调用；自动采集与模型整理由后台定时任务执行，并设有滚动 24 小时调用上限；外部推送默认关闭。
