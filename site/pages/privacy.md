# 隐私说明（朋友试用）

版本：2026-10-18。CinemaHOT 由 Joseph 管理，部署于 AWS 美国俄勒冈服务器，供朋友试用。隐私相关查询、更正或删除请求可通过反馈页提出。

## 浏览器数据

收藏、已读、主题、最近搜索、更新日志已读状态和反馈草稿保存在当前浏览器；列表位置和展开状态使用会话存储。这些偏好不通过账户同步，清除浏览器数据会删除它们。

## 反馈与管理

主动提交的反馈文字、选填邮箱、页面地址与截图存储在该 AWS 服务器的数据库或文件目录，由 Joseph 查看处理。系统使用由网络地址与浏览器类别计算的不可逆标识进行限流。管理员登录使用会话 Cookie，后台不向公网开放。

反馈目前没有自动删除期限；如需删除请通过反馈页提出，由管理者核对相关文件后处理。请勿在反馈中填写密码、API key 或其他敏感材料。

## 日志与第三方服务

服务运行及错误日志可能包含请求路径、运行状态和错误信息。容器日志采用限量轮转，反馈数据不因此自动删除。启用模型整理时，公开新闻文本会发送到 DeepSeek API 生成摘要、分类与评分。目前飞书、外部推送和对象存储备份未启用。

sslip.io 提供域名解析，证书机构提供 HTTPS 证书，AWS 提供服务器基础设施。点击原文链接会访问第三方网站；远程图片可能向原站发出请求，适用相应服务的隐私规则。将来启用采集、模型或推送等外部服务时，应更新本说明。
